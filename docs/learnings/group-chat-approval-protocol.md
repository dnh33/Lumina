# Group Chat Approval Protocol

## Context
Lumina team chat: agents were self-approving features by asking "@hermes for permission" — the @hermes persona, not the actual user. User corrected: "You guys always ask @hermes for permission, not me. As he's the team lead."

## Key Learning
- **@user is the decision-maker**, not the @hermes persona
- **Execution of pre-approved work**: agents can proceed without asking
- **Judgment calls** (new features, scope changes, brand decisions): must surface to @user with explicit yes/no options
- **Self-approval cascade**: forbidden — agents confirming each other's decisions is an anti-pattern
