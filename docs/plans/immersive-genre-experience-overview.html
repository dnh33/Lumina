Lumina · Ideation Overview

Immersive Curated Genre-Specific Experience

A new standalone page where you pick a genre and go deep: an atmospheric "world" plus curated rails, optionally guided by the existing Companion. This is the consolidated pre-plan snapshot of everything researched, grilled, and decided so far.

Branch: immersive-curated-genre-specific-experie Status: DESIGN, build gated 12 research strands + 4-agent grill 5 STILL-BLOCKING to resolve

1. The concept

The inverse of today's breadth-first Discover. discoverService.forYou already OR's your top-3 genres into one spread; this reuses the same engine with an explicit genre seed for a focused, narrative, deep dive. It must feel like entering a world, not scrolling a list, while staying usable, fast, and accessible.

Positioning

The world, not the feed

A poster rail is the fallback. The goal is genre-scoped immersion: a threshold entry, a curated spine, and AI guidance that walks you through a place that knows your taste.

Reuse, don't invent

Built on what exists

Anti-fatigue anchor machinery (anchorService) is the differentiator: the world reads fatigue, never writes it. insightService.titleInsight, contextBuilder, chatService, tools all feed it.

2. The per-genre feel layer

The blunt verdict from the feature-richness audit: a tint-swap is not enough. Feel is a parameter map over the locked system, not new assets. True structural difference lives in the genre-module blocks (Timeline, Geo, Watch-order, Topic-cluster), not in decoration.

Six spatial metaphors (each drives hero composition + one signature gesture + Companion register)

✦

Sci-Fi · Constellation

Posters as charted stars; Memory Constellation motif. Precision, glacial awe.

⌖

Horror · Threshold

Dread then visceral hold, then confront, then release. Tight, uneasy type.

❡

Documentary · Reading Room

Curiosity to absorption to counter-argument to understanding. Editorial, credible.

♡

Romance · Warm Interior

Anticipation, intimacy, reflection, warmth. Soft, generous tracking.

⌒

Western · Frontier

Restlessness, expanse, trial, settlement. Woodcut-weight, blunt.

▦

Anime · Panel

Discovery, kinetic immersion, lore. Most expressive optical setting.

4. Scope: what actually ships

The grill corrected an overclaim: "8 universal devices" was itself a recolored shell. The MVP must include one real structural module to not be a tint-swap.

v1 (MVP, not a shell)

Universal + Timeline module

Shell + 4 editorial devices (Argument spine, Maker spotlight, You-Are-Here, Echoes) + 4 universal elements (Compare, Critic/Credibility, Start-Here, Save/Resume) + ONE cross-genre module: the Timeline/Era scrubber, live for all genres via genreWorld config. Real scrubbable temporal axis.

v1.5 (modules)

Genre modules via config

Geo Map, Topic Cluster, Watch-order Sequencer, Critic nuance, switched on per genre. One component parameterized over genreWorld, not N page variants.

Proof-genre scope: ship 3 proof genres (Documentary, Sci-Fi, Horror) with distinct registers. Defer the full 13-genre matrix. Cut Quote pull-quotes + Mood/Soundtrack cue-mapping from v1.

5. Grill findings (pre-plan must-fix)

A 4-agent grill-with-docs team challenged the design against the real repo. Verified by me, not agent-assertion. These become hard code-review gates in the build.

G1
Still-blocking

forYou has no genre-seed param (discoverService.ts:99). "Reuse with explicit seed" is a modification, not a drop-in call. Phase-2 scopes a new/modified engine (explicit seed → ids.join("|") OR logic).

G2
Still-blocking

bare filterCatalog is a silent regression. It does NOT read getExcludedGenres (default []); only flag() does (discoverService.ts:27-50). New service MUST call flag(db, items) or it silently shows ignored/genre-excluded titles. Hard gate.

G3
Still-blocking

Doc self-contradicts on anchor logging. §7 "on view logs anchor" vs R3 "never on view." Current code logs only on title-open (insightService.ts:234 take, :272 insight_neighbors ×3, tools.ts:586 compare_titles). Forbid log-on-view; reuse :263-273 only inside a real open action.

G4
Still-blocking

ChatDock collision. Global, hidden ONLY on /chat (App.tsx:16,51) → it floats over /genre, double-companioning the world's own surface. Decision: hide ChatDock on /genre too.

G5
Still-blocking

v1-universal-only is STILL a recolored shell. Corrected: true structural differentiation needs v1.5 genre-modules. v1 must include ≥1 real module (Timeline) to not be a tint-swap.

G6
Verified-safe

"One batched LLM call" is admitted-NEW code (not drop-in); keywords/origin_country gap real; anchorService exports + discover_titles OR/year caps + ChatDock existence all confirmed; documentary exemplar F1/F10 anchors ALL REAL.

G7
Verified-safe

§13.7 overclaim corrected: "8 interaction families = rich enough" conflated device count with structural differentiation. v1 = shell + 4 devices + 4 elements + Timeline module.

G8
Scope cut

13-genre matrix → 3 proof genres (Doc/Sci-Fi/Horror). Keep Argument spine, Maker spotlight, You-Are-Here, Echoes; cut Quote pull-quotes + Mood/Soundtrack. F2/F3/F4/F5 deferred to v1.5.
