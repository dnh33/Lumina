## Design Context

### Users
Daniel (primary): builder-cinephile who runs Lumina local-first as a private archive and taste companion. Opens the app to (1) log/rate/track, (2) decide what to watch tonight from *his* history, (3) talk to something that actually knows his taste, (4) never get spoiled. Values speed, density, honest labels, keyboard paths. Quality bar: professional, slick, state of the art — not an art project.

### Brand Personality
Composed · knowing · hush. Boutique-cinema friend when summoned; private screening vault when browsing. Voice: eloquent, warm, precise (companion prompts); UI chrome stays quiet and material. Three-word personality: **composed, knowing, hush.**

### Aesthetic Direction
**Feel:** Archive-backed projection booth — personal shelf as ground truth, one cinematic “tonight” pull above the fold, companion as summoned presence (not lobby).
**References:** Criterion / boutique cinema editorial hush · Apple TV+ poster polish & restraint · Aetherkeep observatory (gold-as-signal, grain, info density).
**Anti-references:** Generic dark SaaS · Letterboxd social chrome · AI chatbot lobby · purple haze · Inter stack · Sparkles/✦ as AI shorthand · gold inflation · pill soup · precious art-project / museum boutique.
**Theme:** Dark only (`color-scheme: dark`). Ink theater, rare gold intermission light, film grain atmosphere.
**Type:** Fraunces (voice, film titles, greetings) · Public Sans (UI/body — kills Inter) · JetBrains Mono (meta/data, rare).

### Design Principles
1. **Elevate, never dull** — Success gate: does this feel *more vault-like* than today? Facelift adds aesthetic density and usage value. Strip only AI-slop tells. If cleaner but lesser → reject. Ban “quieter/greyer = better.”
2. **Gold = luxury hierarchy, not austerity** — No hard “≤3 gold” quota as a win condition. Judge *earned vs inflated*. Prefer richer, better-staged gold (tonight hero, live companion, earned verdicts, active CTAs) over less gold. Glow stays on live/active/earned — refine FAB glow, don’t kill it for dogma.
3. **Every cut needs a richer replace** — Purple → warm ink/projection ambient. Inter → Public Sans (+ JetBrains meta). Sparkles/✦ → presence primitive / earned memory marks. Gold-on-every-hover → lift/edge/vignette hover + gold on focus/active. Hollow welcome → archive-aware dealt-in posters. Never bare removal.
4. **Personal before popular** — Discover opens on *his* continuum with a cinematic Tonight pull — spectacle *and* ownership, not charts-as-hero.
5. **Art heroic; chrome more material** — Posters/backdrops stay worship-grade (Apple TV focus, Criterion lockups). Chrome gains lacquer/glass/catchlight/grain — lose nested SaaS card soup, not depth.
6. **Fraunces speaks; Public Sans works** — Type upgrade is a gain in character, never a demotion.
7. **Motion and presence add life** — Keep/intensify state vocabulary, deal-in, confirms, dock craft. Kill only meaningless motion. Hush on `/` = *placement* (not chatbot lobby), not *less light*.
8. **Nothing sacred if the vault improves** — Rewrite internals to add value/aesthetics; never “simplify” into a lesser product.

### Council guardrails (accidental dulling)
- Killing FAB glow for “rare gold” → glow stays on live/active; cut decorative gold only
- Flattening panels to anti-card voids → keep material depth; lose nested borders
- Muting presence for “serious” → keep state vocabulary + confirms; kill noise only
